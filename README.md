# Dav Lewis website

Static site, no build step.

## Editing the content
Open `content.js` and change the text. Instructions are at the top of that file. You never need to touch the `.html` files or `site.js`.

## Publishing
Push to GitHub, then Settings > Pages > deploy from the branch root.

## Testing locally
Double-click `index.html` to open it in your browser. Refresh after editing `content.js`.
